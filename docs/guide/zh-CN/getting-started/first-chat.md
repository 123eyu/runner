# 第一次聊天

开始一次聊天，让一个智能体在自己的终端中工作。你可以直接选择智能体，也可以使用已保存指令和设置的角色。

## 开始并完成一个小任务

1. [安装智能体并登录](install.md)，然后打开 Runner。
2. 按 **⌘N** / **Ctrl+N** 打开 **开始对话（Start a chat）** 。如果焦点位于空窗格，聊天会填入其中；否则会在新标签页中启动。
3. 选择 **直接对话（Direct）** 并选择智能体，或选择 **角色（Role）** ，再选择已保存的角色，例如 **Coder** 。预置的 Coder 角色需要 Codex。模型和推理强度选项取决于智能体；保留默认值会使用智能体或角色配置。
4. 将 **工作目录（Working directory）** 设为你希望智能体读取的文件夹。选择项目可以自动提供此路径。启动前请核对路径。
5. 点击 **开始对话（Start chat）** ，或按 **⌘Enter** / **Ctrl+Enter** 。
6. 在终端中发送一个小提示，例如：“列出此文件夹顶层的文件，并解释各自的用途。不要修改任何文件。”在智能体自己的终端中完成登录、目录信任或审批提示。
7. 等待智能体回复。你可以继续在它的终端中追问。完成后，使用会话控制区的 **停止（Stop）** ，或在该会话获得焦点时按 **⇧⌘X** / **Ctrl+Shift+X** 。

停止的聊天会保留在 Runner 中。如果运行时支持， **恢复（Resume）** 或 **⇧⌘R** / **Ctrl+Shift+R** 会继续已保存的对话。[会话](../concepts/sessions.md)解释了停止、恢复和关闭的区别。

## 添加另一个窗格

按 **⌘D** / **Ctrl+D** 向右拆分，或按 **⇧⌘D** / **Ctrl+Shift+D** 向下拆分。在空窗格中使用 **新建对话（New chat）** 选择另一个智能体或角色。每个窗格都有独立会话；拆分不会复制第一个智能体的对话，也不会创建任务。

## 打开 Shell

按 **⌥F12** / **Alt+F12** 显示聊天标签页的终端抽屉。你可以在保持智能体可见的同时运行 `git status` 等命令。再次按此快捷键可将其隐藏。也可以按 **⌘T** / **Ctrl+Shift+T** 启动独立的终端标签页。

## 关闭并稍后返回

Runner 的后台服务负责管理会话。在 **设置 → 通用 → 退出 Runner 时（Settings → General → When Runner quits）** 中，可以选择询问、保持会话运行或停止会话。选择 **保持运行（Keep running）** 后，重新打开 Runner 会连接到仍在运行的终端。同一区域的 **启动时恢复运行中的智能体（Resume running agents on launch）** 控制 Runner 停止原本正在运行的智能体后的恢复行为；它不会自动重启所有手动停止的聊天。

如需让团队共同完成一个任务，请继续阅读[第一个任务](first-mission.md)。
