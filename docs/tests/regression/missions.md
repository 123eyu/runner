# Missions

Use only temporary ledger-listed roles, crews and missions under the [procedure](../full-smoke-test.md). A bounded QA request must explicitly cover any multi-slot or watch-host agents needed by a row. Reuse owned configurations when safe. Evidence for delivery includes the submitted native notice/transcript, exact event ID, covering `inbox_read` and a receiver ACK or once-only marker, rather than Working alone. Use the version-matched development CLI and help for payload shapes.

Current authority: [router](../../../crates/runner-daemon/src/router/mod.rs), [delivery handlers](../../../crates/runner-daemon/src/router/handlers.rs), [delivery gate](../../../crates/runner-daemon/src/session/manager/mod.rs), [mission operations](../../../crates/runner-daemon/src/ops/mission.rs) and [workspace](../../../crates/runner-app/src/surfaces/mission_workspace/mod.rs).
