# Settings

Use native UI plus disk/CLI readback for writes. All install, skill, MCP, update and agent-configuration actions require test-owned isolated fixtures or explicit authorization for that exact existing installation. Ordinary live account reuse does not authorize changing global settings. Use the [procedure](../full-smoke-test.md), retain original fixture state and restore test changes. Package/update rows require separately supplied authorized artifacts and environments; a development preview cannot prove a production installation.

Current authority: [Settings](../../../crates/runner-app/src/surfaces/settings_page.rs), [Agents actions](../../../crates/runner-app/src/surfaces/settings/agents.rs), [agent update terminal](../../../crates/runner-app/src/surfaces/agent_update.rs), [skills](../../../crates/runner-app/src/surfaces/settings/skills.rs), [appearance](../../../crates/runner-app/src/appearance.rs), [MCP](../../../crates/runner-app/src/surfaces/settings/mcp.rs), [command installer](../../../crates/runner-daemon/src/cli_install.rs), [managed skill](../../../crates/runner-daemon/src/agent_skill.rs), [Windows updater](../../../crates/runner-app/src/updater/windows.rs) and [Windows update contract](../../arch/windows.md#update-behavior).
